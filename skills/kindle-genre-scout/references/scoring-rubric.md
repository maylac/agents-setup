# Kindle Genre Scoring Rubric

各項目1〜5点、合計30点満点。20点超を推薦対象とする。

| 項目 | 問い |
| --- | --- |
| 需要シグナル | 読者はこの悩みをすでに自覚し、検索しているか?(サジェスト・上位本レビュー数で観察) |
| 競合の隙 | 上位本に「古い・浅い・読みにくい」等の付け入る隙があるか?強豪だらけなら低点 |
| 著者適合 | 著者の体験・実績で本文に固有の価値を足せるか?(Gate 1で埋まる見込み) |
| リスト導線適性 | 読後に特典→LINE/メルマガへ自然に誘導できるテーマか?(将来拡張の布石) |
| 継続性 | 同テーマで2冊目以降(シリーズ化)が出せるか?冊数スケールに効く |
| 安全性 | 断定リスク(医療・金融・法律・収益保証)を免責と根拠で管理できるか? |

## Red Flags(即却下)

- 「AIで人生が変わる」のような読者不在の抽象テーマ
- 著者が体験ゼロで、web調査の要約しか書けないテーマ(churn and burn化する)
- 収益・健康・法律の断定的な約束を売りにするテーマ
- 上位が出版社・有名著者で固められ、レビュー数の桁が違うカテゴリ

## 有効なテーマパターン

- 「<具体的な状況の人>が<期間>で<具体的な状態>になるための本」
- 経験者しか書けない失敗談ベースの実践ガイド
- 大きな定番テーマ×狭い読者属性(例: 総論ではなく「〜な人のための」)
- 自分の仕事・生活で検証済みのワークフローの公開
